# Controle PRISMA

Este arquivo serve para acompanhar a preparação do relato. Use a checklist oficial PRISMA correspondente à revisão e registre aqui o andamento, sem substituir o documento oficial.

- [ ] Checklist oficial consultada
- [ ] Título identifica o trabalho como revisão sistemática, quando aplicável
- [ ] Resumo estruturado conforme orientação aplicável
- [ ] Objetivos e questões claramente descritos
- [ ] Critérios de elegibilidade relatados
- [ ] Fontes de informação e datas das buscas relatadas
- [ ] Estratégias completas de busca disponibilizadas
- [ ] Processo de seleção descrito
- [ ] Processo de extração descrito
- [ ] Avaliação de qualidade/risco de viés descrita, quando aplicável
- [ ] Métodos de síntese descritos
- [ ] Fluxo de seleção apresentado
- [ ] Estudos excluídos em texto completo e motivos registrados
- [ ] Estudos incluídos apresentados
- [ ] Limitações discutidas
- [ ] Registro/protocolo informado, quando aplicável
- [ ] Materiais, dados e código disponibilizados conforme possível

Referência oficial: https://www.prisma-statement.org/prisma-2020
