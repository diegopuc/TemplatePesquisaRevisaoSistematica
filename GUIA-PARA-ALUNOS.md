# Guia Rápido para os Alunos

## Antes de começar

1. Preencher o `README.md`.
2. Elaborar e revisar `01-protocolo/protocolo.md`.
3. Definir as questões de pesquisa.
4. Definir os critérios de inclusão e exclusão.
5. Validar o protocolo com o professor/orientador.
6. Somente depois iniciar a execução das buscas.

## Durante a revisão

- Registrar cada busca em `02-estrategia-busca/registro-buscas.csv`.
- Preservar as exportações originais em `03-identificacao/resultados-brutos/`.
- Registrar as decisões de seleção nas planilhas correspondentes.
- Usar sempre o mesmo `id_estudo` para um artigo em todas as etapas.
- Registrar alterações metodológicas em `01-protocolo/alteracoes-protocolo.md`.
- Atualizar o andamento no `README.md`.

## Commits sugeridos

```text
protocolo: define questões de pesquisa
busca: adiciona string da Scopus
busca: registra execução de 2026-08-18
triagem: conclui primeira rodada de títulos e resumos
eligibilidade: registra motivos de exclusão
extracao: adiciona dados dos estudos E001-E010
analise: adiciona síntese da RQ1
prisma: atualiza números do fluxograma
```

## Cuidados

Não versionar senhas, chaves de API, informações pessoais, dados confidenciais ou artigos protegidos por direitos autorais sem autorização.
